## 1. MISSION

Build a complete, polished, original 2D top-down farming life-simulation RPG that runs in the browser as an installable offline-capable web app. The game should feel like a beloved 16-bit-era farming game: calm pacing, warm pixel art, chiptune music, daily routines, seasonal change, a small village full of characters with their own lives, and a heartfelt main story.

Working title: **Willowmere Acres**.

Target play length: a full main story across 2.5 in-game years (roughly 25-35 hours of play), with indefinite post-game.

## 4. ARCHITECTURE

### 4.1 Principles

- Game logic is pure TypeScript with no Phaser imports, living in `src/systems/`. Phaser scenes only render state and forward input as commands.
- One serializable `GameState` object is the single source of truth. Systems are functions `(state, command | tick, rng) => state changes + emitted events`.
- Deterministic simulation: given the same seed and same input commands, the game produces identical state. This is tested.
- Content is data-driven. Adding a crop, NPC, recipe, or event requires only a data change, not code.
- Typed event bus for decoupling (e.g., `ItemShipped`, `DayEnded`, `FriendshipChanged`, `FlagSet`, `StoryBeatTriggered`).

### 4.2 Directory layout

    src/
      main.ts
      config.ts
      core/            event bus, rng, clock, command queue, flags, localization
      state/           GameState types, factory for new game, save schema versions, migrations
      systems/         time, calendar, weather, stamina, tools, soil, crops, trees, animals,
                       inventory, economy, shipping, shops, upgrades, relationships, schedules,
                       pathfinding, dialogue, events, quests, journal, festivals, fishing, mining,
                       foraging, cooking, processing, achievements, evaluation, mail, tv
      data/            crops, trees, items, tools, animals, npcs, gifts, dialogue, schedules,
                       events, festivals, recipes, shops, mail, tv, quests, journal pages,
                       achievements, maps index, strings (en)
      data/schemas/    Zod schemas for every data file
      scenes/          Boot, Preload, Title, NewGame, Intro, World (one scene class that loads
                       any map), Interior, Mine, Festival, Cutscene, UIOverlay, Dialogue,
                       PauseMenu, Inventory, Shop, Calendar, Journal, Relationships,
                       Collections, Options, NightSummary, Evaluation, Credits
      render/          sprite factories, y-sorting, lighting/tint, weather particles, camera
      ui/              widgets: window frame, dialogue box, choice list, item grid, tooltip,
                       hearts, clock, stamina bar, toast, touch controls
      audio/           sequencer, instruments, song data, SFX generator, mixer, ducking
      input/           keyboard, gamepad, touch, rebinding, input contexts
      debug/           debug menu, overlays, state inspector
    tools/             asset generators (sprites, tiles, portraits, font, music render, maps)
    tests/unit/  tests/e2e/  tests/sim/
    public/            manifest, icons (generated)

### 4.3 Scene flow

Boot → Preload (progress bar) → Title → (New Game → Character Setup → Intro Cutscene) or (Continue / Load) → World. UIOverlay runs in parallel with World. Modal scenes (Dialogue, Shop, Inventory, PauseMenu, etc.) pause the World clock.

### 4.4 Entities and rendering

- Lightweight entity model: player, NPCs, animals, crops, debris, interactables, pickups.
- Y-sorted depth for everything on the object layer.
- Collision via tile collision layer plus per-entity hitboxes (feet-based).
- NPC pathfinding: A* on the tile grid, cached per map, with door/warp nodes for cross-map travel. NPCs off-screen are simulated logically (position along schedule) without rendering.

## 5. PRESENTATION

### 5.1 Resolution and scaling

- Internal resolution 320x240 (4:3). Integer scaling to the largest multiple that fits; letterbox the rest with a subtle seasonal pattern.
- Optional "pixel-perfect off" smoothing setting is not offered; always crisp nearest-neighbor.

### 5.2 Palette

- Define a 48-color master palette in `tools/palette.ts` (warm greens, soft earth browns, sky blues, sunset oranges, muted purples for night, plus UI neutrals).
- Every generated asset uses only palette colors. A unit test scans every generated PNG and fails if any off-palette pixel exists.
- Per-season palette swap tables for terrain and foliage (spring fresh green, summer saturated, autumn amber/red, winter white/blue-grey).

### 5.3 Art direction

- Chibi proportions: characters 16x24 pixels on a 16x16 grid (head roughly 10px tall).
- 1px dark outline (not pure black; a deep palette tone), top-left light source, 2-3 shade ramps per material.
- Friendly rounded shapes, no harsh contrast.

### 5.5 Tiles and maps

- 16x16 tiles with 47-tile blob autotiling for grass/dirt/tilled soil/water/sand/snow edges.
- Animated tiles: water (4 frames), waterfall, flowers swaying, torches, Lantern Tree glow.
- Map layers: Ground, GroundDetail, Collision, Objects (y-sorted), AbovePlayer, Lights, Warps, Spawns, Triggers.

### 5.6 Lighting and time-of-day

- Full-screen multiply tint driven by a 24-hour color curve (dawn pink, day neutral, dusk orange, night deep blue).
- Additive light sprites for windows, lamps, lanterns, campfires, mine torches, fireflies (summer nights).
- Interiors use their own fixed lighting with window light changing by time.

### 5.7 Weather visuals

Sunny, cloudy (soft shadow drift), rain (particles + puddle ripples + darker tint), storm (heavier rain, wind-bent particles, lightning flash + delayed thunder), snow (drifting particles, gradual ground snow cover), blizzard (reduced visibility vignette), autumn wind (falling leaves), spring petals.

### 5.8 UI

- Window frames: 9-slice, wood-and-cream style, generated.
- HUD: clock with day/season/weekday and weather icon, money counter with roll animation, stamina bar with face icon that changes expression, equipped tool + held item slots.
- Dialogue box: bottom third, portrait on the left, name tag, typewriter text with per-character blip sound, configurable speed, auto-advance option, choice lists with cursor, inline item icons and colored keywords.
- Toast notifications for items gained, friendship changes (optional setting), achievements.
- Bitmap pixel font generated by `tools/font.ts` (5x7 regular plus 8x8 bold title variant), supports full Latin-1 for future localization.
- Title screen: animated farm vista with parallax clouds, original pixel logo, seasonal variant matching the latest save.

## 8. CORE GAME DESIGN

### 8.1 Premise (brief; full story in Section 13)

The player inherits a neglected farm in the village of Willowmere from their great-aunt Wren, who has left to travel. The village faces a council vote at the end of Year 3 Spring on whether to sell the valley to a mining consortium. The player's success influences the vote.

### 8.2 Time and calendar

- 4 seasons x 30 days. Seasons: Spring, Summer, Autumn, Winter. Weekdays: Mon-Sun.
- Clock runs 6:00 to 2:00. Default speed: 1 in-game minute = 0.7 real seconds (adjustable: 0.5x, 1x, 1.5x, 2x in options).
- Time pauses during dialogue, menus, cutscenes, and festivals' scripted segments.
- Sleeping before midnight restores full stamina; after midnight restores 75%; collapsing at 2:00 restores 50%, costs 10% of money (max 1,000G), and plays a short scene where a villager found the player.
- Calendar screen with festivals, birthdays, and player-placed markers.

### 8.3 Stamina and fatigue

- Stamina max starts at 100. Tool costs: hoe 2, watering can 2, axe 4, hammer 4, sickle 1, fishing cast 3, upgraded charge uses cost scaled by area.
- Fatigue (hidden, 0-100) increases when stamina is low or the player works in rain/snow without eating. High fatigue lowers stamina regeneration and can cause a cold (bedridden next day) if ignored.
- 10 hidden Sunroot Fragments in the world each add +10 max stamina (found via exploration, festival prizes, mine depths, story rewards). Each has a short discovery scene.
- Food restores stamina and reduces fatigue; cooked dishes restore more and some give buffs (speed, luck in mining, fishing ease) for the day.
- Hot spring on the mountain restores stamina over time while standing in it.

### 8.4 Tools and upgrades

- Upgrades at the blacksmith: cost money + ore bars, take 2 days, the tool is unavailable meanwhile.
- Ore smelting at the blacksmith (fee) or player-owned furnace after an upgrade.

### 8.5 Farming

- Field debris on new game: weeds, stones, branches, stumps, boulders, logs randomly placed (seeded) across an 80x64-tile farm with a ~40x30 central field.
- Soil states: untilled, tilled-dry, tilled-wet, fertilized (3 grades), seeded. Tilled soil without seeds reverts after 3 dry days.
- Seeds are sown in a 3x3 pattern per bag around the player (genre convention), or single tile with a "precise sow" option for accessibility.
- Crops only grow on days they were watered (or it rained). They wither at season change unless in the greenhouse.
- Crop quality (Normal, Good, Excellent, Superb) based on fertilizer grade, consecutive watered days, and a seeded roll.
- Storms have a chance to damage unprotected crops (scarecrow-style "Wind Ward" item protects a radius).
- Crows/pests event: unprotected fields may lose 1-3 crops overnight (original "Crow Kite" decoration protects a radius).
- Grass can be planted and cut into Fodder (stored in the silo) for animals.

### 8.6 Shipping and economy

- Shipping bin beside the house; contents sell overnight. Nightly Summary screen lists each item, quantity, quality, and total, with a satisfying coin animation and sound.
- Shops buy some items directly at lower prices.
- Starting money: 500G. Clear income curve target: by end of Spring Year 1, a diligent player earns 15,000-25,000G total.
- Economic sinks: seeds, animals, feed, tool upgrades, buildings, house upgrades, furniture/decor, gifts, festival entry, recipes.
- Price stat tracking per item (lifetime shipped quantity and money) for collections and evaluation.

### 8.7 Livestock

- Buildings: Coop (4 chickens → 8 → 12 on upgrades), Barn (4 large animals → 8 → 12), Silo (fodder storage 200 → 500 → 999).
- Animals: Chicken, Cow, Sheep, plus a farm dog or cat chosen at the start (pet affection, follows player, reacts to weather).
- Daily care: feed (fodder in trough or grass outdoors), talk/pet, brush (large animals), let out on sunny non-winter days via a door toggle, bring in before night (or wolves-free original rule: animals left out in rain get stressed).
- Affection 0-255, shown as 10 hearts. Affects product quality: eggs (Normal/Golden), milk (S/M/L/Golden), wool (S/M/L/Golden).
- Sickness from neglect or storms; cure with Animal Tonic. Animals never die permanently; severe neglect makes them leave the farm with a sad note (recoverable via the animal shop).
- Breeding: Cow/Sheep breeding item, 21-day gestation, calf/lamb grows into adult after 14 days. Chickens: place egg in incubator, 3 days to hatch, 7 days to adult.
- Naming dialog on purchase/birth with profanity-safe validation and length limits.
- Processing: Mayonnaise Maker, Cheese Press, Spinning Wheel, Jam Pot, Pickling Jar (each a placeable machine, processing over hours, higher value outputs).
- Animal contests at festivals (Section 12).

### 8.8 Fishing

- Cast with charge meter (distance). Wait for bite (randomized timing via seeded RNG, with visual bobber dip and sound).
- Reeling minigame (original design): a moving "fish marker" on a curved reel arc; the player holds/releases to keep a catch window over it while a tension meter must stay out of the red. Fish have behavior profiles (calm, darting, sinker, leaper).
- At least 24 fish across river, lake, ocean, and mine pond, each with seasons, times, weather conditions, size range, and price.
- Fish records (largest caught) in collections. Fishing contest at a summer festival.

### 8.9 Foraging

- Seasonal forage spawns in the forest, mountain, beach, and farm edges (12+ forage items per season across locations), respawning every few days.
- Hidden spots (behind waterfalls, under bridges) for rare forage.
- Beach shells and tide-dependent items.

### 8.10 Mining

- The Old Copper Mine entrance on the mountain. 60 procedurally generated floors (seeded per day per floor).
- Floor generation: cave rooms with rocks, ore nodes, gem nodes, ladder hidden under a random rock, occasional treasure chest, rare "crystal pocket" floors every 10 floors.
- Ores: Bronze, Iron, Silversteel, Starglass shards. Gems: 10 original gem types for gifts and selling.
- No combat; difficulty comes from stamina, lighting (deeper floors darker, lantern upgrade), and cave-ins (if the player stays too long on deep floors, a gentle cave-in sends them back to the entrance with lost found items).
- Elevator checkpoints every 10 floors after story chapter progress.
- Story Hearthstone found on floor 50 (Section 13).

### 8.11 Cooking

- Kitchen unlocked with the first house upgrade.
- At least 40 recipes, each requiring 2-5 ingredients and optionally a utensil (pot, pan, oven, mixer, knife).
- Recipe sources: villager gifts at friendship thresholds, TV cooking show (original "Willowmere Kitchen" program each Monday and Thursday), journal pages, experimentation (mixing unknown combos teaches recipes when correct).
- Dishes have stamina/fatigue values and some daily buffs.

### 8.12 Buildings, house, and decor

- Carpenter (Bram) offers: House upgrade 1 (kitchen, bigger room), House upgrade 2 (bedroom, nursery possible), House upgrade 3 (cellar for aging cheese/jam), Coop/Barn upgrades, Silo upgrades, Greenhouse, Fences, Paths, Furnace, Well relocation, Stable for a riding horse.
- Horse obtained via a story beat in Year 1 Summer; can be ridden for faster travel; can carry items to ship from the field (saddle bag).
- Upgrades take 3 days with a visible construction scaffold on the farm.
- Furniture catalog (40+ items) and wallpaper/flooring (10 each) for house decoration with a placement mode (grid snapping, rotation where applicable).

### 8.13 Mail and TV

- Mailbox: letters from Aunt Wren (one per season, story-linked), shop catalogs, villager thank-you notes, birthday reminders, Halverd's polite letters.
- TV with 4 channels: weather forecast (accurate for tomorrow, 90% for the day after), cooking show, village news (dynamic: mentions player achievements), and a lore channel telling original folk tales of the valley.

### 8.14 Requests board

- Board outside the general store with 1-3 villager requests per week (deliver item, catch fish, find lost item, help with event). Rewards: money, friendship, rare items, recipes. Drives village exploration.

### 10.1 Schedules

- Data format: per villager, a list of schedule rules with conditions (season, weekday, weather, festival, story flags, relationship status) and time-stamped destinations with facing direction and idle animation.
- NPCs walk between locations in real time using pathfinding; they open doors, sit on benches, work behind counters, go home at night.
- A debug overlay shows each NPC's current target and path.

### 10.2 Gifts and friendship

- Friendship points 0-1000 per villager, shown as 10 hearts.
- Talk once per day: +10. Gifts (once per day, max 2 per week per villager): loved +80, liked +45, neutral +15, disliked -20, hated -40. Birthday gifts x8. Quality bonus for crops/animal products.
- Decay: -2/day if not spoken to for 7+ days (not below the highest unlocked heart event's threshold minus 50).
- Gift reactions: unique line per loved item category per villager plus generic lines.

## 11. ROMANCE, MARRIAGE, AND FAMILY

- Five romanceable adults (Ivy, Kip, Ansel, Lira, Sable). The player may date any of them regardless of the player character's chosen body type.
- Dating requires 8 hearts + giving a Willow Ribbon (original courtship item sold by Ozzie after 7 hearts with anyone). Dating unlocks date events at specific locations.
- Proposal requires 10 hearts, House upgrade 2, and the Hearth Ring (crafted from a Lumenberry and a Starglass shard, story-linked after the Winter chapter or purchasable late game).
- Wedding: a full scripted ceremony at the Chapel of Seasons with all villagers attending, unique dialogue from each, and the Wedding theme.
- Spouse moves into the house, has a daily routine (helps water some crops or feed animals on random days), daily dialogue pool (60+ lines), reacts to weather/season/events, has 4 post-marriage heart events.
- A child can join the family one year after marriage (choice between birth announcement or adoption, presented respectfully). The child grows through 3 visual stages over a year and has simple interactions.
- Rejection, jealousy, and breakup mechanics are not included; keep it gentle.

## 13. MAIN STORYLINE

### 13.1 Tone

Warm, gently humorous, occasionally bittersweet. The player character is mostly silent except for dialogue choices (2-3 options), which sometimes affect outcomes and later dialogue.

### 13.2 Intro (new game)

1. Short cutscene: a gray city office at night, the player at a desk, a letter arrives. Text-only narration over pixel scenes.
2. Aunt Wren's letter (shown on screen in full): she has left to travel, gives the player the farm, asks them to "look after the valley and the tree."
3. Arrival by cart at Willowmere Square. Mayor Odalie greets the player, explains the farm's state and, after some hesitation, the upcoming council vote and Halverd's offer.
4. Tutorial day guided by Odalie and Rosalind: clear debris, till, plant turnips, water, ship, sleep. Tutorial is skippable after the first step for returning players.

### 13.3 Act structure

**Act I — Roots (Year 1 Spring to Year 1 Summer 15)**

- Meet all villagers (introductions tracked in the Journal).
- Discover Wren's first journal page under the farmhouse floorboard on Spring 3.
- Chapter 1: "The Stone in the Roots." Restore the old orchard plot on the farm: clear it (needs Iron Axe and Hammer), plant 3 fruit saplings bought through Bram's old contacts, ship 50 spring crops total, reach 3 hearts with Bram. Bram reveals Wren helped build his workshop. Reward: the Spring Hearthstone, found inside the oldest stump once cleared, and a cutscene in which the Lantern Tree shows one faint glowing bud.
- Halverd's first visit (Spring 18): offers to buy the farm; player chooses a polite, firm, or curious response (affects his arc dialogue).

**Act II — Currents (Year 1 Summer 15 to Year 1 Autumn end)**

- Chapter 2: "The Stone Under the Falls." Corran refuses to talk about the sea. Through fishing (catch 15 species), helping Lira repair her boat (deliver materials), and 4 hearts with Corran, the player learns Corran's family stopped sailing after a storm years ago in which Wren helped save them. Lira and the player sail to a hidden cove behind the Mirebrook waterfall's sea side. Reward: Summer Hearthstone, second bud on the Lantern Tree.
- The horse arrives (story gift from Rosalind after Chapter 2 begins).
- Chapter 3: "The Stone in the Deep." Greta refuses Wren's name. Reach mine floor 50, where the player finds an old forge chamber with Wren's and Greta's initials. Greta's arc reveals they were best friends who fell out over Greta's choice to stay in the valley instead of traveling. A letter from Wren to Greta resolves it. Reward: Autumn Hearthstone, third bud.
- Halverd's summer and autumn visits escalate: he buys a stake in the inn's debt (sets up Marta's arc) and surveys the mountain.

**Act III — Hearth (Year 1 Winter to Year 2 Winter)**

- Chapter 4: "The Stone in the Hearth." The Longnight Gathering is in danger of being canceled (Odalie overwhelmed, the inn struggling). The player must reach 3+ hearts with at least 10 villagers and help 3 villager arcs reach their midpoint. At the Gathering, villagers each bring something, Keeper Ilse explains that the fourth Hearthstone was never a stone but the hearth of the village itself, and a glowing ember appears in the hearth. Reward: Winter Hearthstone.
- Year 2 Spring 1: Lantern Bloom cutscene (the tree blooms fully, all villagers present, the Lantern Tree Bloom theme plays). The Lantern Bloom Vigil festival is unlocked permanently.
- Year 2 continues with villager arcs, marriage opportunities, and Halverd's arc resolution: the player learns he grew up in a mining town that collapsed economically, and he believes he's offering Willowmere a lifeline. His arc can end with him resigning from the consortium and opening a small surveying office in the village (if the player completes his 3 events), or simply departing.

**Act IV — The Vote (Year 3 Spring)**

- Year 3 Spring 28: Council Vote cutscene in the town hall. Each villager speaks briefly, referencing what the player did for them.
- Aunt Wren returns for the vote if the player found at least 12 of 16 journal pages; she gives a speech and stays in the village afterward as an NPC with her own dialogue pool and schedule.

### 13.4 Journal pages (16 total)

Each page has a title, a short handwritten-style text (80-150 words, original), and a hint or reward (recipe, map marker, or lore). Sources: farmhouse floorboard, orchard stump, library archives (Fenwick at 4 hearts), Corran's chest, the hidden cove, mine floors 20/40/60, Greta's forge, Ember Walk, Longnight Gathering, Ozzie's rare stock, Wren's letters (2), Keeper Ilse (6 hearts), and the summit lookout at dawn in winter.

### 13.5 Evaluation and endings

Score components: Lantern Tree restored (major weight), villager arcs completed, average friendship, farm rating (total shipped, animals' average affection, crop variety shipped, buildings), collections completion, festival participation, marriage.

| Ending               | Condition                            | Outcome                                                                                                                               |
| -------------------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------- |
| Thriving Willowmere  | High score + Lantern Tree restored   | Vote unanimous; player named honorary council member; festival montage; credits                                                       |
| Steady Willowmere    | Medium score + Lantern Tree restored | Vote passes narrowly; hopeful epilogue                                                                                                |
| Uncertain Willowmere | Lantern Tree not restored            | Vote fails, sale delayed one year; play continues; completing the Lantern Tree later triggers a revote and the best ending achievable |

There is no permanent bad ending. After the ending, the game continues indefinitely with post-game content: deeper mine rewards, rare fish, decor sets, Wren as a villager, and yearly Lantern Bloom Vigil.

## 14. VILLAGER ARCS

Each arc: 4-5 events, clear beginning, conflict, turning point, resolution. Triggers combine friendship, flags, date, and location. At least one arc choice changes the outcome.

1. **Marta and the Inn** — debts bought by Halverd's consortium. Player helps through supplying ingredients, a fundraiser at a festival, and convincing Odalie to support it. Outcome: inn saved and renovated (visible map change) or inn becomes a co-op run by villagers (both positive).
2. **Dex: Leave or Stay** — the player's choices guide Dex. He either leaves for the city (sends letters, visits each Winter) or stays and starts a music night at the inn. Both endings respected.
3. **Hollis and June** — estranged siblings over their late parents' bee farm. Reconciliation via helping both, culminating at Harvest Scales.
4. **Dr. Ansel's Burnout** — the player notices fatigue cues; helping him find a substitute doctor schedule; romance path variant if dating.
5. **Sable the Newcomer** — awkward newcomer painting the valley; their gallery opening at the town hall; villagers' portraits displayed (visible map change).
6. **Ivy's Bakery** — supply ingredients, help her convince her parents; a bakery opens in the general store's side room (new shop items).
7. **Kip's Confidence** — Kip leads the animal show at Harvest Scales.
8. **Lira's Boat** — repairs lead to ocean deep-fishing unlocks.
9. **Halverd** — see Act III.

Completed arcs are listed in the Journal with a short epilogue paragraph.

## 15. DIALOGUE AND EVENT SYSTEM

### 15.1 Dialogue data

- Lines are keyed with conditions: friendship range, season, weather, weekday, time of day, location, flags, relationship status, recent events (e.g., player shipped 100 crops yesterday, player is married, it is the villager's birthday).
- Selection picks the most specific matching line not shown in the last N days.
- Markup supports: speaker portrait expression changes mid-line, pauses, text speed changes, colored keywords, item icons, player name insertion, choices with outcomes (set flags, change friendship, give/take items, start events).

### 15.2 Cutscene scripting

- Event scripts as typed data: sequences of commands (move NPC to tile, face, emote bubble, play animation, show dialogue, choice branch, camera pan, fade, play music/SFX, wait, set flag, give item, change map, weather override).
- Event triggers: enter map, interact, time window, flags, friendship thresholds, festival segment.
- Events are skippable on replay (after seen once) and log to the Journal.

### 15.3 Writing quality

- All lines are fully written, in-character, and varied. Each villager has a distinct voice described in their data notes (vocabulary, sentence length, catchphrase avoidance of real-world brands).
- Total written content target: at least 2,500 unique dialogue lines across all villagers, events, festivals, mail, TV, and journal pages. Report the final count in the Final Report.

### 22.1 Unit (Vitest) — coverage threshold 85% lines on `src/systems` and `src/core`

- Dialogue selection specificity and no-repeat window.
- Event trigger conditions and flag effects.
- Evaluation scoring and ending tier selection.
- Save migrations, export/import checksum, corruption recovery.
- Palette compliance of every generated PNG.
- Data validation: every Zod schema passes; every item referenced in recipes/gifts/shops exists; every dialogue key exists in strings.

### 22.2 E2E (Playwright, Chromium + Firefox + WebKit + mobile viewport)

1. Boot to title, start new game, complete character setup.
2. Clear a tile, till, plant, water, sleep 4 days, harvest, ship, verify money in Night Summary.
3. Buy a chicken (via debug money), place it, collect an egg the next day.
4. Talk to and gift a villager, verify friendship increase.
5. Save, reload the page, load the slot, verify state equality (hash of GameState).
6. Enter mine, descend 3 floors, exit.
7. Trigger a festival via debug and complete its minigame.
8. Offline: load once, go offline, reload, play a day.
9. Touch controls: mobile viewport, move and use a tool via virtual buttons.

### 22.3 Simulation (`pnpm sim`)

- Headless bot player using logic systems only. Bot strategy: farm, care for animals, talk to villagers, give liked gifts, fish on rainy days, mine on weekends.
- Runs 2.5 in-game years with 5 different seeds. Asserts: no exceptions, no NaN/negative money, every villager reachable each day, main story completable (bot follows story hints via flags), evaluation reaches at least the Steady ending, and economy curve lands within BALANCE.md target ranges.
- Determinism test: same seed and command log produce identical final state hash.
- `pnpm check` runs a short sim (1 season, 1 seed); the full sim runs before the final report.

### 22.4 Fuzz

- Random command sequences (10,000 steps x 20 seeds) against systems; assert invariants (inventory counts non-negative, no item duplication, time monotonic, save/load roundtrip equality).
